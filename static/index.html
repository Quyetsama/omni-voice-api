Cách Tích Hợp API Vào Ứng Dụng Của Bạn

Vì giọng đã được lưu trong cache, bạn chỉ cần gửi request HTTP POST cực nhẹ kèm voice_id là có thể nhận về file âm thanh.

Python (requests) 
import requests

# 1. Sinh âm thanh bằng giọng đã lưu trong Cache
response = requests.post(
    "http://localhost:8000/tts",
    json={
        "text": "Xin chào thế giới!",
        "voice_id": "giong_mc_nam", # Thay bằng voice_id của bạn
        "speed": 1.0
    }
)

with open("output.wav", "wb") as f:
    f.write(response.content)
print("Đã lưu file output.wav!")
JavaScript / Node.js (Fetch) 
async function playSpeech(text, voiceId = "giong_mc_nam") {
  const res = await fetch("http://localhost:8000/tts", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ text, voice_id: voiceId, speed: 1.0 })
  });
  const blob = await res.blob();
  const audio = new Audio(URL.createObjectURL(blob));
  audio.play();
}

playSpeech("Chào bạn, tôi là trợ lý AI!");
